Memeriksa sesi login…

1. Buat Akun Pengurus Baru

Super Admin dapat membuat username dan password awal di sini, tanpa membuka Supabase setiap kali. Fitur ini memerlukan aktivasi satu kali Edge Function create-staff-account di Supabase. Password tidak disimpan di halaman ini.

Akun baru hanya memperoleh hak sesuai jabatan yang diberikan. Simpan password awal secara aman dan berikan langsung kepada pemilik akun.

2. Edit Jabatan dan Akses Akun

3. Ubah Password Login

Pilih akun melalui tombol Edit pada daftar akun. Super Admin dapat mengganti password pengurus tanpa mengetahui password lama. Untuk password akun Super Admin sendiri, gunakan tombol khusus di bawah.

Fitur reset password pengurus memerlukan Edge Function reset-staff-password yang dipasang satu kali di Supabase. Jangan kirim password melalui chat.

Ubah Password Saya Sendiri

Untuk akun Super Admin yang sedang login, ubah password langsung melalui Supabase tanpa Edge Function.

Daftar Akun Pengurus

Pilih Edit untuk mengubah jabatan atau menonaktifkan akses. Penghapusan akun login dilakukan melalui Supabase Authentication.
