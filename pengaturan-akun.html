Memeriksa sesi login…

1. Buat akun login terlebih dahulu

Buka Supabase → Authentication → Users → Add user, masukkan email resmi pengurus dan atur password awal melalui fitur Supabase. Salin UID pengguna tersebut, lalu kembali ke halaman ini untuk menetapkan jabatan.

Jangan mengirim password melalui chat. Setiap pengurus harus menggunakan akun pribadi. Jika pertama kali menggunakan menu ini, jalankan supabase-account-management.sql dari repository di SQL Editor Supabase.

Buka Supabase Dashboard ↗

2. Atur jabatan dan akses

Daftar Akun Pengurus

Pilih Edit untuk mengubah jabatan atau menonaktifkan akses. Penghapusan akun login dilakukan melalui Supabase Authentication.
