# GMIM SILO WATULINEY

Website informasi publik GMIM SILO WATULINEY, tahap awal.

## Halaman
- `index.html`: beranda, profil, jadwal ibadah, 16 kolom, kegiatan, kontak.
- `admin.html`: pemberitahuan portal pengurus belum aktif.

## GitHub Pages
Buka **Settings → Pages → Build and deployment**, pilih **Deploy from a branch**, branch **main**, folder **/(root)**, lalu **Save**.

Alamat setelah publikasi: https://hiijee220.github.io/GMIM-SILO-WATULINEY/

## Keamanan
Jangan unggah data jemaat asli, file Excel pribadi, password, bukti transaksi, atau kunci API ke repository publik. GitHub Pages tidak menjalankan backend dan database. Login admin yang aman akan dibuat pada tahap berikutnya dengan backend terpisah.

## Konten
Jadwal ibadah, sejarah, alamat dan pengumuman saat ini placeholder dan perlu diverifikasi oleh pengurus.
